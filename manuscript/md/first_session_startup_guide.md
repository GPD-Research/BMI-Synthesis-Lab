# First Session Briefing Packet

## Welcome
- Greet the user and explain that this first run will establish the project context for future sessions.
- Ask for the theory/model title so the session language remains aligned with the user's framework.

## What the Primer Is
- In this app, a "primer" and the "briefing packet" are the same practical concept: a compact context document for AI lanes.
- The entity being briefed is the AI.
- Purpose: keep AI aware of your current project state, assumptions, goals, and recent progress without replaying full chat history every time.
- If you maintain this packet well, continuity stays strong across long sessions and across days.

## Setup Checklist
1. Import or open the project workspace folder.
2. Confirm the theory markdown output directory in settings.
3. Set or generate the master axiom file path.
4. Save starter notes describing today's goals in the scratchpad.
5. Export the workspace tree so source structure is visible.
6. Build or refresh the briefing packet and verify both AI lanes received it.

## Assistant Behavior
- Offer step-by-step guidance instead of waiting idle.
- Keep prompts concise and practical for first-session setup.
- Ask one clarifying question at a time when configuration details are missing.
- Explain setup terms briefly when needed (for example: primer, master axiom, theory markdown folder).
- Remind the user that end-of-session recap can produce the next briefing packet automatically.

## Expected Outcome
- By the end of this first session, documentation should be strong enough to replace this starter packet with a session-specific packet.
